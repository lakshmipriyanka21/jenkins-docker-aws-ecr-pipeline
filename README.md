

**# Jenkins Docker AWS ECR CI/CD Pipeline**



**## Project Overview**

**Automated Docker image build and push to AWS ECR using Jenkins.**



**## Technologies**

**- Jenkins**

**- Docker**

**- AWS ECR**

**- AWS IAM**

**- GitHub**



**## Architecture**

**Jenkins Pipeline → Docker Build → AWS ECR**



**## Pipeline Stages**

**1. Build Docker image**

**2. Authenticate to AWS ECR**

**3. Tag Docker image**

**4. Push image to AWS ECR**



**## Project Files**

**- Dockerfile: Nginx test container**

**- Jenkinsfile: CI/CD automation**



**## Result**

**Jenkins Build #3 completed successfully and pushed**

**the Docker image to AWS ECR.**



**## Note**

**This is an Nginx demonstration image, not the actual**

**Spring Boot Petclinic application.**

**AWS EKS deployment is not included.**
